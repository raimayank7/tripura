How the code ICIC0002147 is built

ICIC is the bank part: the letters of ICICI Bank. The fifth character is always the digit 0. 002147 is the part that names this branch.

The MICR code 799229501 is the number printed along the bottom of this branch's cheques. 799 is the city (the same three digits that begin the PIN code 799205), 229 is the bank and 501 is the branch.
